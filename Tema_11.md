### Задание 2

``` git
class CountDown:
    def __init__(self, start):
        self.count = start + 1
    
    def __iter__(self):
        return self
    
    def __next__(self):
        self.count -= 1
        if self.count < 0:
            raise StopIteration
        return self.count

if __name__ == '__main__':
    counter = CountDown(5)
    for i in counter:
        print(i)
```

![Меню](https://github.com/WladCher/SoftwareEngineering/blob/Tema_11/pic/lab2.jpg)

## Выводы
Класс CountDown создаёт собственный итератор с помощью методов iter() и next(), позволяя управлять порядком обхода, моментом остановки и состоянием счётчика. В отличие от списка, такой итератор не держит все элементы в памяти, а формирует их по запросу

### Задание 5

``` git
def countdown(count):
    while count >= 0:
        yield count
        count -= 1

if __name__ == '__main__':
    counter = countdown(5)
    for i in counter:
        print(i)
```
### Результат.
![Меню](https://github.com/WladCher/SoftwareEngineering/blob/Tema_11/pic/lab5.jpg)

## Выводы
Функция countdown() создаёт генератор через yield. Каждый yield приостанавливает выполнение функции и возвращает текущее значение, сохраняя состояние для следующего вызова. Такой способ позволяет формировать последовательности без хранения всех элементов заранее, как в обычных итераторах

Применение yield создаёт ленивый генератор, выдающий по одному элементу за раз без сохранения всей последовательности в памяти. Такой подход эффективен при работе с большими объёмами данных, экономит ресурсы и быстрее списков

### Задание 2

``` git
def fib(n):
    a, b = 1, 1

    for _ in range(n):
        yield a
        a, b = b, a + b


if __name__ == "__main__":
    nums = list(fib(200))

    print("1–200 числа Фибоначчи:")
    print(*nums)

    with open("fib.txt", "w") as f:
        for number in nums:
            f.write(str(number) + "\n")
```

## Общие выводы по теме

Итераторы и генераторы позволяют эффективно работать с последовательностями данных, особенно при больших объёмах информации


Итераторы — это объекты с методами iter() и next(), выдающие элементы по одному и сохраняющие своё состояние между вызовами. Такой подход экономит память, так как все элементы не хранятся одновременно

Генераторы — это специальные функции с yield, автоматически создающие итераторы и возвращающие значения по мере запроса

Компактная запись генераторов без создания списка в памяти называется генераторными выражениями

Итераторы дают контроль над обходом, а генераторы делают код лаконичным и эффективным. Вместе они обеспечивают “ленивые вычисления” в Python, что важно для производительности и экономии ресурсов
